# Python Web Scraping Projects

## About
This repository contains my beginner Python web scraping projects. I am learning how to collect website data, extract information, organize it using Pandas, and export it to CSV and Excel files.

## Tools & Libraries
- Python
- Requests
- BeautifulSoup
- Pandas
- Excel
- CSV

## Projects

### 1. Books Scraper
Extracts book titles, prices, ratings, and availability from a practice website.

### 2. Quotes Scraper
Extracts quotes, authors, and tags from a practice website.

### 3. Big Dataset Scraper
Scrapes multiple pages of book data and collects records into CSV and Excel files.

## Skills Practiced
- HTTP requests
- HTML parsing
- `find()` and `find_all()`
- Loops
- Lists
- Pagination
- Data extraction
- Pandas DataFrames
- CSV and Excel exports

## Learning Purpose
These projects are created for educational and practice purposes using websites intended for scraping practice.
